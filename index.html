FAQ

Questions before you download

Common things players ask about the Chapter 5 trainer.

Is the trainer safe to use?
The project is fully open source, so every line can be reviewed on the repository. Builds are compiled from the published source and contain no telemetry, no bundled installers, and no auto-updaters. Always download from the official gitscore.cc link rather than mirrors.
Will it work with the Steam version of Chapter 5?
Yes. The trainer targets the current Steam build for Windows 10 and 11, including the 64-bit executable. After a game patch, offsets may need an update — check the release notes for a version matching your build.
Can I get banned for using it?
Poppy Playtime Chapter 5 is a single-player story game with no VAC-protected multiplayer, so the trainer is intended purely for solo play, practice, and exploration. That said, use it at your own risk and avoid running it in any online-enabled mode.
How do I write custom Lua cheats?
Place a .lua file in the lua/ folder next to the executable. The injector exposes hooks for player stats, entity lists, and input binding — full documentation and example scripts ship with the download.
